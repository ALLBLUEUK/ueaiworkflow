# Model Diagnosis

Help students interpret:

- command or script purpose
- model assumption
- input file
- output table
- error message
- economic meaning

For `贸易数据库与分析工具`, focus on GEMPACK, GTAP, input output analysis, welfare decomposition, and policy shock interpretation.
