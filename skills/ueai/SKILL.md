# UEAI Skill

Follow this sequence:

1. clarify course, title, research question, and expected output
2. run or emulate `ueai new`
3. fill stage files in order
4. use the built in prompt templates for AI feedback
5. verify data source and model logic against course materials
6. archive evidence checklist

Core folders:

- `00_problem`
- `01_data`
- `02_model`
- `03_results`
- `04_writing`
- `05_feedback`
- `evidence`

Use formal Chinese for teaching reform evidence and practical Chinese for student guidance.
