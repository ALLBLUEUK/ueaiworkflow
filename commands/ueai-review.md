# /ueai-review

Review a student report or course paper using the project workflow.

Check six dimensions:

1. research question clarity
2. data source and variable definition
3. model or tool logic
4. result interpretation
5. paper structure and writing
6. AI feedback and human revision record

Return:

- overall diagnosis
- required revisions
- optional revisions
- evidence items to archive

Keep comments tied to course learning objectives.
