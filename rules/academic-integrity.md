# Rule: 学术诚信与 AI 使用披露

适用范围：本工作流产出的所有作业、报告与论文。

## 学生承诺

提交任何使用本工作流的成果时，学生须在论文 / 报告中加入「学术诚信声明」段，覆盖：

1. **使用的 AI 工具**：模型名称、版本号、调用方式（本地 / API / 网页）。
2. **使用环节**：列出在 00–05 哪些阶段使用、占整体工作量约百分之几（粗估）。
3. **AI 提供的是什么**：建议清单、代码骨架、文本反馈，**不是**最终数据 / 系数 / 结论。
4. **本人完成的是什么**：数据核验、模型运行、结果判读、最终文本。
5. **数据真实性承诺**：所有数据均从公开数据库 / 课程提供数据导出，未经伪造或拼接。

## 禁止行为

- 将 AI 生成的 HS 编码、GTAP 集合、回归系数当作真实结果。
- 用 AI 写完整段落且不做实质修改即提交。
- 删除 / 修改 AI 反馈日志以掩盖使用过程。
- 跨阶段共享 AI 生成的同一份 outline 在多个课程重复提交。

## 教师义务

- 课程开始时讲明本规则。
- 评分时优先看 `## 人工核验与修改` 与 `05_feedback/ai_revision_log.md`。
- 不强制要求零 AI 使用 —— 但要求**披露**。
