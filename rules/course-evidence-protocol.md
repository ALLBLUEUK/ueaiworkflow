# Course Evidence Protocol

Every course project should keep evidence in four categories:

1. task file: assignment prompt, report requirement, or paper requirement
2. process file: data notes, model notes, AI feedback, and human revision log
3. output file: final report, paper, presentation, or table
4. summary file: anonymized student output count and teaching use description

Public repositories should contain templates and anonymized samples. Private folders should hold student submissions, grades, and identifiable materials.
